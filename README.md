# Simple Text-Based Roulette Game

This is a simple console-based simulation of a classic single-zero roulette game written in Python. Players can bet on a single number (0-36) and see if they win based on a random spin.

## Features

•   Simulates a roulette spin returning a number from 0 to 36.

•   Allows the player to bet a specific amount on a single number.

•   Validates player input for bet amount (positive, within balance) and bet number (0-36).

•   Calculates winnings based on a 35:1 payout for betting on a single number.

•   Tracks the player's balance throughout the game.

•   Continues playing until the player runs out of money or chooses to quit.
